# Five Useful Commands I Learned

ls -lah — Lists files and directories, including hidden files. It displays permissions, ownership, file sizes in a human-readable format, and modification dates and times.

mv projects/demo/test.txt projects/demo/backup.txt — Renames test.txt to backup.txt. The mv command can also be used to move files from one location to another.

rm projects/demo/backup.txt — Deletes the backup.txt file from the specified directory.

less /var/log/syslog — Allows me to view the contents of the system log file one screen at a time. I can scroll through the file at my own pace without modifying it.

cat /etc/passwd — Prints the contents of the /etc/passwd file directly to the terminal.
